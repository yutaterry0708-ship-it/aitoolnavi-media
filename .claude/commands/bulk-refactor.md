ultracode を適用し、動的ワークフロー（Dynamic Workflows）モードを開始してください。

ミッション: $ARGUMENTS

実行手順:
1. 監査サブエージェントを立ち上げ、変更対象となるすべてのファイルをリストアップし、依存関係グラフを作ってください。
2. 対象ファイルごとにワーカーサブエージェントを割り当ててください。競合を避けるため、必ず Git のワークツリー（isolation: worktree）を使って並列に変更してください。
3. 検証サブエージェントを立ち上げ、変更後のコードが構文チェックを通り、`cd src && python static_publisher.py` が成功することを確認してください（このリポジトリにテストスイートはありません）。エラーがあればワーカーに差し戻して修正させてください。
4. すべて完了したら変更のサマリーレポートを提示し、私が確認できるようにコミットの準備まで済ませてください（push はしない）。

制約: API 課金や外部投稿が発生するスクリプト（CLAUDE.md の表を参照）は実行しないこと。
