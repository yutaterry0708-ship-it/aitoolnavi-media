ultrathink を適用して、このプロジェクトで「$ARGUMENTS」に関する問題を極めて深く調査してください。

重要事項:
1. まだ一行もコードを修正・記述しないでください。Plan Mode として振る舞ってください。
2. まず関連するすべてのファイル（依存関係、呼び出し元、`config.yaml`、`.github/workflows/daily.yml` など）を特定し、Read ツールで内容とデータフロー（`data/keywords.csv` → `content/` → `docs/`）を把握してください。
3. 以下の4つの観点から多角的に分析してください。
   - エッジケースと未定義の動作
   - パフォーマンスと API コストへの影響
   - セキュリティ上の懸念（インジェクション、秘密情報の漏洩、権限バイパス）
   - 既存のアーキテクチャパターン（CLAUDE.md 記載）からの逸脱
4. 分析が終わったら、3つの異なる解決アプローチ（それぞれのメリットとデメリットを含む）を提示し、私の指示を待ってください。
